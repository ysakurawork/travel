# Travel Archive

個人・家族向けの旅行アーカイブ。

## v1
- 地図を主役にした旅行詳細ページ
- キルギス・カザフスタン 2026 の旅程
- レスポンシブ対応
- 写真・感想は後から追加

## 公開設計
本番では Supabase Auth を利用し、招待済みユーザーのみ閲覧可能にする。
管理者は Supabase Dashboard から閲覧ユーザーを確認・招待・削除する。
